# Организация кода

Код для документа **PriceMatchingOut** (исходящий ЗЦ, работа со стороны Покупателя)

### Модуль Торги.s3mod в сервисе online

Ядро работы с документом

[https://git.sbis.ru/tender/sbis3-tender/-/tree/rc-26.6100/www/service/%D0%A2%D0%BE%D1%80%D0%B3%D0%B8/tender\_online/etp/price\_matching?ref\_type=heads](https://git.sbis.ru/tender/sbis3-tender/-/tree/rc-26.6100/www/service/%D0%A2%D0%BE%D1%80%D0%B3%D0%B8/tender_online/etp/price_matching?ref_type=heads)

- `price_matching_out.py` — обработчики событий исходящего ЗЦ (создание, чтение, фазы, `state_changed`, restore, возможные операции)
- `price_matching_reader.py` — чтение карточки / параметры регламента
- `price_matching_winners.py` — выбор победителей (`winners_selected`)
- `offer.py` — оферы/ставки

[https://git.sbis.ru/tender/sbis3-tender/-/tree/rc-26.6100/www/service/%D0%A2%D0%BE%D1%80%D0%B3%D0%B8/tender\_online/etp?ref\_type=heads](https://git.sbis.ru/tender/sbis3-tender/-/tree/rc-26.6100/www/service/%D0%A2%D0%BE%D1%80%D0%B3%D0%B8/tender_online/etp?ref_type=heads)

- **`price_matching_card.py`** — карточка документа (`get_application_info`)
- **`price_matching_attach.py`** — прикрепление вложения за участника
- **`participant.py`** — участники ЭТП (создание/удаление)

Точки входа — подписки в `on_event.py` (события `online.pricematchingout*`) и реализация в `Торги.orx`.

### Модуль Tender.s3mod в сервисе TenderWS

Действия с

[https://git.sbis.ru/tender/sbis3-tender/-/tree/rc-26.6100/tender-service/applications/Tender/TenderService/price\_matching?ref\_type=heads](https://git.sbis.ru/tender/sbis3-tender/-/tree/rc-26.6100/tender-service/applications/Tender/TenderService/price_matching?ref_type=heads)

- `price_matching_out.py` — бизнес-логика исходящего ЗЦ
- `price_matching_attach.py`, `attach_rights.py` — вложения
- `participant_offer.py`, `best_offers.py`, `nomenclature.py`, `common.py`
- `price_matching_winners.py` — победители

Работа с заявками

[https://git.sbis.ru/tender/sbis3-tender/-/tree/rc-26.6100/tender-service/applications/Tender/TenderService/tensor\_tp/participant?ref\_type=heads](https://git.sbis.ru/tender/sbis3-tender/-/tree/rc-26.6100/tender-service/applications/Tender/TenderService/tensor_tp/participant?ref_type=heads)

- `price_matching.py` (`ParticipantPriceRequest`), `base.py`, `factory.py`

Класс-ядро `TenderPriceMatchingOut` объявлен в `Торги.orx`, его методы через `EndPoint('tender').TenderPriceMatchingOut.*` вызывают функции из `tender-service/.../price_matching/*`.
