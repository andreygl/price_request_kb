# База данных

Описание в [БЗ Складских документов](https://link.saby.ru/page/kbase_entity/01a9e45d-b671-4ebb-b9af-b599b21c8a4e?folderId=ff81fd61-89fc-4e50-b88b-7eddafacbd7f).

Ниже описаны типовые выборки, касающиеся таблиц в БД Торгов.

### **Типовые выборки**

**Получение связанного торга для документа - 1**

Получаем для документа информацию по связанному торгу для получения участников, информации о победителях.

Алгоритм выборки:

- выбираем идентификатор торга по uuid документа из таблицы tender2uuid

**Список участников запроса цен - 2**

Показываем для каждого участника название компании, email, статус приглашений

Алгоритм выборки:

- выбираем участников из таблицы result на основе идентификатора торга
- из связанной таблицы participant получаем данные по организации
- по каждой заявке из таблицы result из таблицы resultitem агрегируем позиции и получаем количество и сумму

**Получение информации по предложению поставщика/добавленным данным от покупателя - 3**

Получаем комментарий поставщика, комментарий организатора, дату получения заявки

Алгоритм выборки:

- обращаемся к таблице result

**Получение цен по предложению поставщика/добавленным данным покупателем - 4**

Показываем цены выбранного участника по позициям, измененные цены покупателем

Алгоритм выборки:

- обращаемся к таблице resultitem

**Получение лучших ценовых предложений - 5**

Отчет по лучшим ценовым предложениям. Позиции запроса цен группируем по поставщикам с минимальными ценами.

Алгоритм выборки:

- для всех заявок внутри торга от поставщиков result делаем join на их ценовые предложения resultitem
- группируем ценовые предложения по номеру позиции resultitem.position\_number (позиция товара в предложении) сортируем их в порядке: сам покупатель поставил флаг лучшее, сумма меньше, больше предложенных ценовых позиций и нумеруем оконной функцией row\_number
- группируем ценовые предложения по номеру позиции resultitem.position\_number (позиция товара в предложении), сортируем в том же порядке. Вызываем array\_agg над группировкой с формирование информации о поставщике participant.brief и цене за единицу resultitem.unit\_price и берем первый элемент массива
- группируем ценовые предложения по номеру позиции resultitem.position\_number (позиция товара в предложении), сортируем в том же порядке. Вызываем array\_agg над группировкой с получением resultitem.@resultitem и берем первый элемент массива
- выборку обертываем запросом и отбираем позиции с row\_number = 1 - получаем лучшие ценовые предложения по каждой товарной позиции resultitem.position\_number

### **Индексы**

Используемые индексы

1. tender2uuid(uuid). Используется в выборке 1
2. result(tenderid). Используется в выборке 2,5
3. participant(sppid). Используется в выборке 2,5
4. resultitem(resultid). Используется в выборке 2,4,5
5. result(@result). Используется в выборке 3
