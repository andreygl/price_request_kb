# Архив раздела «Запрос цен»

Здесь лежат исходные страницы раздела до перестройки. Они не актуальны и оставлены только для истории и сверки.

- `Запрос цен на стороне покупателя/` — исходные страницы исходящего документа.
- `Запрос цен на стороне поставщика/` — исходные страницы входящего документа.
- `База данных (исходная).md` — исходная страница БД с выборками и индексами.

Актуальные страницы раздела находятся в корне папки «Запрос цен». Правила ведения и история изменений — в `Changelog.md` и `Правила ведения раздела.md`.
