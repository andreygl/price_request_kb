# Организация кода

Код для документа **PriceMatchingIn** (входящий ЗЦ, работа со стороны Поставщика)

### **Модуль Торги.s3mod в сервисе online**

[https://git.sbis.ru/tender/sbis3-tender/-/tree/rc-26.6100/www/service/%D0%A2%D0%BE%D1%80%D0%B3%D0%B8/tender\_online?ref\_type=heads](https://git.sbis.ru/tender/sbis3-tender/-/tree/rc-26.6100/www/service/%D0%A2%D0%BE%D1%80%D0%B3%D0%B8/tender_online?ref_type=heads)

- **`etp/price_matching/price_matching_in.py`** — обработчики событий входящего ЗЦ (создание, чтение `price_matching_in_read`, `general_info`, `extra_info`, `product_list`, `save_changes`, фазы `before/after_phase_executed`, `in_create`)
- **`etp/participant.py`** — фасад участника (заявки, создание/удаление участника с ЭДО, контакты)
- **`etp/price_matching/offer.py`** — оферы/ставки поставщика
- **`etp/price_matching_attach.py`** — вложения участника (`process_participant_attachment`, `delete_participant_attachments`)
- **`etp/price_matching_card.py`** — карточка ЗЦ для поставщика (`get_application_info`)
- **`we_participate.py`** — приглашения поставщика (`WeParticipate.GetInvitations`)

Подписки — события `online.pricematchingin*` в `on_event.py`, реализации — `Торги.orx` (объекты `PriceMatchingWnIn`, `TenderPriceMatchingIn`).

### **Модуль Tender.s3mod в сервисе TenderWS**

[https://git.sbis.ru/tender/sbis3-tender/-/tree/rc-26.6100/tender-service/applications/Tender/TenderService?ref\_type=heads](https://git.sbis.ru/tender/sbis3-tender/-/tree/rc-26.6100/tender-service/applications/Tender/TenderService?ref_type=heads)

- **`price_matching/price_matching_in.py`** — backend-логика входящего ЗЦ (ответ поставщика)
- **`tensor_tp/participant/`** — участники заявок:

  - `price_matching.py` — `ParticipantPriceRequest` (заявки поставщика: `create`, `save_offer_items`, `read`, `list_participants`)
  - `base.py` (`ParticipantBaseRequest`), `factory.py` (`ParticipantFactory`)
- **`price_matching/participant_offer.py`** — ценовые предложения
- **`price_matching/price_matching_attach.py`** — вложения

Взаимодействие: события `online.pricematchingin*` → `Торги.orx` → `EndPoint('tender').TenderPriceMatchingIn.*` → `price_matching/price_matching_in.py` и `tensor_tp/participant/price_matching.py`.
