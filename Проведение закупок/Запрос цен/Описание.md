## **Задачи**

Документ "Запрос Цен" позволяет запросить цены на товары или услуги у разных поставщиков, затем выбрать для заказа лучшее предложение.

Документ позволяет решать следующий задачи.

Покупателю:

-Сформировать перечень необходимых товаров и услуг для получения ценовых предложений

-Выбрать перечень поставщиков для запроса цен, либо позволить любому поставщику предложить свои цены на интересующие товары и услуги

-Запросить цены с помощью отправки документа по ЭДО или с помощью ссылки на внешнюю форму по электронной почте/мессенджеру

-Вносить цены за поставщика самостоятельно, если поставщик использовал для информирования не типовой канал связи

-Сформировать заказ конкретному поставщику

-Привязывать контактные данные к поставщику

Поставщику:

-Предложить свои цену покупателю через saby или с использованием внешней формы

-Приложить перечень вложений для отправки их покупателю

## **Концепт решения**

Документ "Запрос цен" построен на платформенной механике ЭДО с возможностью множественной отправки документа поставщикам (в saby или ссылкой на внешнюю форму), с отслеживанием состояния обработки по каждому поставщику.

Покупатель в аккаунте создает документ Запрос цен (Тип документа - PriceMatchingOut), указывает что хочет купить и кого пригласить. При отправке Запрос цен размещается в открытой части площадки ([в сервисе TenderWS](https://link.sbis.ru/tradesaby/knowledge)), отправляется поставщикам по каналам ЭДО и электронной почте.

По каналу ЭДО Поставщик в аккаунте получает документ Запрос цен (Тип документа - PriceMatchingIn) во "Входящие".

По электронной почте Поставщик получает письмо со ссылкой на внешнюю форму документа.

Работу внешней формы документа обеспечивает [Сервис внешней работы с документами (СВРД)](https://online.sbis.ru/shared/disk/d9118229-b4da-403a-8dcb-0e9e9420cca3).

Покупатель может заполнить ответ на запрос цен за Поставщика, при этом информация сохраняется в сервис TenderWS без отправки Поставщику. Если Поставщик ответит на запрос, то он перезапишет введенные данные Покупателем.

**Входные данные:**

- товары из локального каталога или услуги (вводятся текстом) с указанием количества, которые Покупатель хочет приобрести по наименьшей цене
- список Поставщиков с контактной информацией, которым направят Запрос цен
- описание закупки: срок поставки, условия оплаты, комментарий для Поставщиков, документация по товарам

**Выходные данные:**

- Поставщики, выбранные победителями, с предложенными суммами по позициям товаров и услуг с поясняющей документацией по товарам или предоставляемым услугам.
