# Подключение номера телефона для тестирования отправки сообщений в механизме отправки Запроса цен Поставщикам.

Для того что бы поступали сообщения в telegram, whatsapp, sms и любой другой мессенджер нужно добавить номер телефона в белый список в рамках ВНТ [пример](https://online.saby.ru/opendoc.html?guid=53994c12-3485-4007-9e2c-2f37428a1cca&client=3) и [пример](https://online.saby.ru/doc/eedc4064-09ad-4808-94c7-a29294f5c935?client=3). Без этого не будут поступать сообщения в мессенджеры

Посмотреть наличие номера телефона в белом списке можно [тут](https://test-cloud.sbis.ru/page/settings), текст для поиска aggregator.WhiteList.Apps
