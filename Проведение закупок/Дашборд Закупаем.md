# Управление закупками

В разделе "Закупаем" открывается дашборд с набором виджетов:

- "**Заявки**" - Предложения поставщиков на проводимые нашей компанией закупки: от новых к старым.
- "**Категории**" -  Виджет, состоит из круговой диаграммы с таблицей, отображает топ категорий по сумме наших закупок.
- "**Закупки**" - Виджет отображает список текущих закупок нашей компании, создавать новые закупки на площадке Saby Trade
- "**Поставщики**" - Топ Поставщиков-победителей в наших закупках по сумме победивших заявок.

  Сортируется по сумме побед конкурента от большей к меньшей. Виджет строится по данным из открытых источников.
- "**Закупали**" -  График с объемами закупок, которые провела наша компания за выбранный период и сравнение с прошлым периодом.

Числовые значения в статистических виджетах (все кроме "Закупки" и "Заявки") предоставляют детализацию через стек-панель при клике на числовое значение.

У каждого виджета есть свой реестр, в который можно перейти через "клик" на заголовок виджета.

## Схема сервисов и данных

![](Дашборд%20Закупаем.assets/r1.png)

Для построения виджетов интерфейс обращается в сервис online для получения наших организаций. После этого online вызывает сервис TenderWS, где по переданным идентификаторам наших организаций фильтруем торги, где эти организации являются заказчиками или организаторами. Конечные данные получаем из Elasticsearch (системное имя tender-elasticsearch).

![](Дашборд%20Закупаем.assets/r2.jpg)

Для аукционов, [запросов цен](https://online.sbis.ru/shared/disk/22014404-aad9-488c-83cb-7fa7d503e149) и всех данных с внешних площадок создаётся сущность торг. Поэтому для получения полных данных будем работать именно с торгами.

![](Дашборд%20Закупаем.assets/r3.jpg)

Торги лежат в таблице public.tender, при индексации они попадают в один из индексов ElasticSearc:

- our\_tender - приватный индекс для черновиков или закрытых торгов, которые не должны быть видны в мониторинге
- tender - открытый индекс, куда попадают торги с внешних источников и опубликованные торги с площадки Saby

### Реестр закупок

![](Дашборд%20Закупаем.assets/r4.jpg)

Реестр закупок строится на основании данных из ElasticSearch, используя оба индекса: закрытый и открытый.

Все необходимые фильтры индексируются из базы в ES и доступны для отбора:

- Статус - stateaggid

  - 2 - Приём заявок
  - 3 - Рассмотрение заявок
  - 1 - Черновик
  - 4 - Завершён
- Категория - saby\_trade\_category
- Регион места поставки

  - delivery\_place\_fias - место поставки, определённое  из торга
  - potential\_delivery\_place\_fias - места поставки, полученные путём парсинга документов торга и вычисление возможных мест поставки в них
- Период - publishdate
- Наши компании - initiator\_spp\_uuid\_list
- Вид торга и открытые/закрытые закупки - proctypeid
- Площадка - tradingplatformid
- Поставщик - participant.spp\_uuid

### Описание источников данных в интерфейсе

**Разводящая страница** раздела "Мы организуем" является дашбордом, методы идут одной цепочкой и вызываются на сервисе представления.

**WeOrganize.get\_offers\_list**  получение списка последних заявок

**TenderWidgets.Category** получение топа категорий

**TenderWidgets.Supplier** получение топа поставщиков

**Реестр поставщиков**

На сервисе представления

**Supplier.GetList** получение списка поставщиков

На клиенте

**Category.GetList/4** получение списка категорий
